# OctoAcme Project Management Docs

This repository contains the OctoAcme program and project management process documents. This README provides a brief summary of the core project management practices and quick links to each process doc stored in the docs/ folder.

## Summary of project management processes

OctoAcme follows an iterative, outcome-driven approach with clear roles and artifacts:

- Initiation: capture the problem, stakeholders, success metrics, and decide go/no-go using a Project One-pager.
- Planning: translate the approved initiative into a prioritized backlog, estimates, and a release/milestone plan.
- Execution & Tracking: run a predictable delivery cadence (standups, weekly syncs, demos), use a project board workflow (Backlog → Ready → In Progress → In Review → QA → Done), and enforce PR and CI conventions.
- Release & Deployment: follow pre-release checks, automated pipelines, smoke tests, and rollback plans.
- Retrospective & Improvement: capture learnings, track action items, and measure impact of process changes.
